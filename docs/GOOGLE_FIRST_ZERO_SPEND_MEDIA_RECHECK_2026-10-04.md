## 2. TTS, Veo ve Cloud TTS: belge var, canlı erişim yok

- **Gemini API TTS:** `gemini-3.8-flash-tts` resmî API dokümanında yer alır. Tek konuşmacı REST yolu Interactions; okunacak metin ile `speech_metadata.style` ayrıdır. Türkçe listelenir; Charon ve Kore hazır ses seçenekleridir. Bu, eski bir UI model adına değil güncel API belgesine dayanır. Ancak canlı model erişimi, talebin kabulü, telaffuz kalitesi ve ticari ses kullanımı burada sınanmadı. [TTS protokolü ve diller](https://ai.google.dev/gemini-api/docs/speech-generation)
- **API fiyatı:** TTS Standard ücretsiz katmanı listelenir. 2026 sonuna kadar Flash TTS ücretli fiyatı metin girişinde 0,50 USD/milyon token, seste 9 USD/milyon token; yayımlanan ses eşdeğeri 10 saniye için 0,00225 USD'dir. Bu hesapta açık ücretsiz kota bulunduğu sonucunu vermez. Veo 3.1 ücretsiz API katmanı yok; Lite 720p için 0,05 USD/s, Fast 720p için 0,10 USD/s, Standard 720/1080p için 0,40 USD/s listelenir. Güncel liste, üretim talebi ve ücret yetkisi yerine geçmez. [API fiyatları](https://ai.google.dev/gemini-api/docs/pricing)
- **Kota:** Gemini API sınırları API anahtarı değil proje bazındadır; model/katmana göre değişir ve etkin sınırlar AI Studio'da görülür. Bu araştırmadan RPM/RPD garantisi üretilmedi. [API kota kuralları](https://ai.google.dev/gemini-api/docs/rate-limits)
- **Cloud Text-to-Speech:** Ayrı Cloud API'dir. Faturalama etkin olmalıdır; ücretsiz karakter miktarı aşılırsa otomatik ücret doğabilir. Standard/WaveNet listesinde ayda ilk 4 milyon karakter, ardından 4 USD/milyon karakter bulunur; bunu diğer ses ailelerine taşımamak gerekir. [Cloud TTS fiyatları](https://cloud.google.com/text-to-speech/pricing)
- **Cloud TTS Türkçe/kota:** Türkçe Standard, WaveNet ve Chirp3-HD kadın/erkek seçenekleri listelenir; `tr-TR-Chirp3-HD-Charon` ve `tr-TR-Chirp3-HD-Kore` vardır. Bunlar Gemini Interactions ses kimlikleriyle aynı API kimliği değildir. Genel metin isteği sınırı 5.000 **bayt**; kota türleri proje ve ses ailesine göre ayrılır. [Ses listesi](https://docs.cloud.google.com/text-to-speech/docs/list-voices-and-types), [Cloud TTS kotaları](https://docs.cloud.google.com/text-to-speech/quotas)

Ücretsiz API katmanı “mahremiyet açısından sınırsız ücretsiz” değildir: Gemini API ücretsiz hizmetlerinde giriş/çıktı ürün geliştirme için kullanılabilir ve insan incelemesi bulunabilir; hassas/kişisel veri gönderilmemesi belirtilir. API şartı kullanıcı için 18+ ve 18 yaş altına yönelik/erişilmesi muhtemel API istemcilerine ilişkin kısıt içerir. **1–8. sınıf uygulamasında doğrudan çocuk→Gemini API entegrasyonu açılmaz.** Yetişkin editörün önceden içerik hazırlaması olası ayrı mimaridir, bu maddeyi otomatik aşmış hukuki çözüm değildir; ürün sahibi/hukuk incelemesi bekler. Bu özel Gemini şartını incelemeden tüm Cloud API'lere aynı metinmiş gibi uygulamıyoruz. [Gemini API şartları](https://ai.google.dev/gemini-api/terms)

Flow'un kendisi de doğrulanmış yaşta 18+ ve desteklenen bölge koşullarını açıklar. [Flow erişim koşulları](https://support.google.com/flow/answer/16353333?hl=en)

## 4. Matematik videosu için ekonomik ve denetlenebilir yön

Öneri **mühendislik çıkarımıdır**, uygulanmış yeni video değildir: kanonik gerekçeli current cue → programatik kalem/vurgu zamanları → her zamana ait kendi SVG karesi → raster kareler → doğrulanmış ses ve düşünme sessizlikleriyle FFmpeg birleştirme. Rakam, tablo, birim ve vurguları Veo'ya yeniden çizdirmek yerine kendi geometri oracle'ımız belirler. Flow/üretken video ileride yalnız ayrı izinli karşılama/illüstrasyon denemesi olabilir; kesin matematik çözümünün kanıt motoru değildir.

[resvg](https://github.com/linebender/resvg) statik SVG rasterleyebilir, MIT veya Apache-2.0 seçeneği sunar; animasyon çalıştırmaz. Bu nedenle her kareyi bizim sahne kodumuz hesaplamalıdır. Fontlar/sürüm/sahne/ölçüler pinlenmeden ortamlar arası piksel eşitliği iddiası kurulmaz. [FFmpeg image2 belgesi](https://ffmpeg.org/ffmpeg-formats.html#image2) görüntü dizisinden video üretimini; [FFmpeg akış seçimi](https://ffmpeg.org/ffmpeg.html) ayrı ses/video girişlerinin tek çıktıya birleştirilmesini açıklar. FFmpeg konuşmanın sözcük-vurgu hizasını kendiliğinden kanıtlamaz.

FFmpeg varsayılan LGPL-2.1+; isteğe bağlı GPL parçalar bütün binary lisansını etkileyebilir (`libx264` dahil). Nonfree/GPL build, binary dağıtımı/linkleme ve codec patentleri ayrı incelenmelidir. “Ücretsiz araç = koşulsuz ticari dağıtım” denmedi. [FFmpeg lisans/hukuk notu](https://ffmpeg.org/legal.html)

Bir sonraki **yetkili yerel teknik** denemede beklenen kanıt: exact cue/metin/voice/byte hashleri; doğru PCM decode ve süre; sözlü sayı/birim eşliği; ayrı sessizlik süreleri; kaynak rakamı örtmeyen kalem; current cue'nun izinli sonucu; gerçek playable video+audio stream/duration/frame sayısı; öğretmen ve dinleyici kabulü. Programatik vurgu gerçek el/el yazısı değildir. Sadece storyboard, SVG/HTML veya sessiz/sentetik PCM receipt; Türkçe seslendirilmiş çözüm videosu teslimi sayılamaz. Yeni sahnenin uçtan uca TTS→kelime/kalem hizası→MP4 hattı bu araştırmada çalıştırılmadı.
